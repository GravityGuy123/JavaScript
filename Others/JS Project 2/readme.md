In Javascript, there are three ways to declare a variable
-let (Used to declare a variable which has a possibility of being modified or redeclared)
-const (Used to declare a variable which you don't have an intention to redeclare it. Which meant it will stay that way till the end of the code)
--var (is used in small scope or funtions or if statements)

Camel Case (The first letter is in lowercase and each new word's first letter is uppercase)

## Ways to declare a string
- Double Quote e.g const name="Gravity";
- Single Quote e.g const name='Gravity';
- Backtick e.g const name=`Gravity`;
**NB:** It is more recomended to use double quote ("") and backtics are mainly used on special cases.
